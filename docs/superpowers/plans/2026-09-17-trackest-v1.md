# Trackest v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A downloadable Android APK: a 64×4 tracker pattern editor that plays through an embedded Csound synth with knob-editable instruments.

**Architecture:** Csound is the clock — pattern cells live in Csound f-tables, a Csound sequencer instr fires notes; Dart writes tables/channels via `dart:ffi` from a dedicated Isolate and reads the play row back. Riverpod `ProjectNotifier` is the single source of truth and forwards edits to an abstract `Engine`.

**Tech Stack:** Flutter 3.32 / Dart 3.8, flutter_riverpod, dart:ffi, Csound 6.18 for Android (`libcsoundandroid.so`, arm64-v8a), Gradle wrapper + Java 21, aarch64 Android SDK tools.

**Spec:** `docs/superpowers/specs/2026-09-17-trackest-v1-design.md`

## Global Constraints

- Android arm64-v8a only; `minSdk 24`.
- Csound: `sr=44100, ksmps=32, nchnls=2, 0dbfs=1`.
- Pattern: 64 rows × 4 channels; 16 instrument slots; instr numbers `10+id`, voice `10+id+ch/10`.
- Cell encodings: note `-1` empty / `-2` off / 0..119; instrument `-1` = keep last; volume `-1` = default, else 0..64.
- Control channels: `bpm`, `lpb`, `playing`, `row`, `i<id>.<param>`.
- Host has no root: SDK installed under `~/android-sdk`; `android.aapt2FromMavenOverride` → aarch64 aapt2.
- Commit after every task with the Co-Authored-By trailer.

- [ ] Implement. Sequencer instr (verbatim into the builder):
```csound
instr 1
  kBpm chnget "bpm"
  kLpb chnget "lpb"
  kPlay chnget "playing"
  kRow init 0
  kWasPlaying init 0
  kTick metro kBpm/60*kLpb
  if kPlay == 0 && kWasPlaying == 1 then
    kRow = 0
    turnoff2 10, 0, 1   ; placeholder loop below releases all
  endif
  if kPlay == 1 && kTick == 1 then
    kCh = 0
    while kCh < 4 do
      kIdx = kRow*4 + kCh
      kNote tab kIdx, 1
      kInst tab kIdx, 2
      kVol tab kIdx, 3
      if kNote >= 0 || kNote == -2 then
        turnoff2 -kCh-1, 4, 1   ; see note: we use named-per-channel tags via p-field, implemented as `turnoff2 kInstrNum` per slot loop
      endif
      if kNote >= 0 then
        kInstUse = (kInst >= 0 ? kInst : 0)
        kVolUse = (kVol >= 0 ? kVol/64 : 0.8)
        event "i", 10 + kInstUse + kCh/10, 0, -1, kNote, kVolUse
      endif
      kCh += 1
    od
    chnset kRow, "row"
    kRow = (kRow + 1) % 64
  endif
  kWasPlaying = kPlay
endin
```
  Voice release rule: before triggering on channel `kCh`, loop `kS` over 0..15 and `turnoff2 10+kS+kCh/10, 4, 1` (release-mode turnoff of the exact fractional voice). On stop, do the same over all 4 channels. (Replace the two placeholder `turnoff2` lines with these loops.)
  Instrument body template (subtractive shown; others analogous, all read `chnget` params, apply `madsr`, scale by `p5`, `outs`):
```csound
instr {{N}}
  iFreq = cpsmidinn(p4)
  kCut chnget "i{{id}}.cutoff"
  kRes chnget "i{{id}}.res"
  kWave chnget "i{{id}}.wave"
  iA chnget "i{{id}}.attack"  ; (i-rate: use chnget at i-time via `i(...)` is not allowed for chnget; use `iA = i(kA)` after `kA chnget`)
  aEnv madsr iA, iD, iS, iR
  aSaw vco2 1, iFreq, (kWave < 0.5 ? 0 : 2)
  aOut moogladder aSaw, kCut, kRes
  outs aOut*aEnv*p5*0.3, aOut*aEnv*p5*0.3
endin
```
- [ ] Run tests → pass. Commit `feat: csound orchestra builder`.
